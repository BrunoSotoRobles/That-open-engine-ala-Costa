# That Open Engine / Costa

## 1. Lisäyksen tarkoitus

Tämän lisäyksen tarkoituksena on kuvata projektin "That Open Engine / Costa" laajuus, ehdot ja rajoitukset, jota kehitetään Bruno Soton työsuhteen aikana Costa Laskenta Oy:ssä.

Projektin tavoitteena on mukauttaa ja toteuttaa BSOTO-web-sovelluksen versio, joka perustuu That Open Engine -teknologiaan, Costa Laskenta Oy:n prosessien, IFC-mallien ja kustannustietokannan integroimiseksi web-työkaluun, joka mahdollistaa IFC-mallien lukemisen, validoinnin ja määrien poiminnan.

## 2. Projektin laajuus

Työsuhteen aikana projektin keskeisiin aktiviteetteihin kuuluvat:

- BSOTO-sovelluksen tekninen mukautus Costa Laskenta Oy:n IFC-mallien ja laskentaprosessien integroimiseksi.

- Erityistoiminnallisuuksien kehittäminen määrien hallintaan, Talo-koodien hallintaan ja yrityksen sisäiseen tietokantaan kytkeytymiseen.

- Testaus, tekninen dokumentointi ja peruskoulutus sovelluksen käyttöön.

Kehitys toteutetaan Costa Laskenta Oy:n infrastruktuuria, dataa ja linjauksia hyödyntäen, ilman alkuperäisen BSOTO-koodin tai siihen liittyvän immateriaalioikeuden siirtoa.
